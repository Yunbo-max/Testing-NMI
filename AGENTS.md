# Agent execution rules — Testing-NMI (human-selected research scope)

Read README.md, docs/RESEARCH_AUTOPILOT.md, docs/H100_COMMANDS.md and agents/AGENT_TASKS.json **before** GPU work. Adopt [Research_Autopilot main](https://github.com/Yunbo-max/Research_Autopilot/tree/main) Human-AI research rules with current pinned procedure; human selected B1 adapter reproduction + controlled experiments; fundamental change to B2 state-reconstruction requires a separate decision.

1. **Scientific contract:** formal object/assumptions → consequential derivation → predicted distinction → falsifier → strong, fairly budgeted comparator → native evidence → independent review → next decision. Reuse confirmed math and failed results; do not fill a candidate quota with repeated names.
2. **Not equivalent:** B1 is not full CED nor CSA2 sparsity. B1 preserves all 64 layers and all GDN dynamics, so never claim half-prefill compute. B1b is the *only* real adaptation implemented; B1a/B1q/B1s/B2 are planned controls or construction tasks until source and tests are added.
3. **Reproducibility:** pin Qwen HF snapshot SHA, transformers revision and exact git commit; freeze train/val/test before running; retain CUDA name, driver, torch, packages, exact commands, stdout/stderr, exit statuses, raw metric JSON, peak memory and independent check. Never fabricate runs.
4. **H100 safety:** measure actual allocated VRAM; no blind full fine-tuning or multiple simultaneous 27B replicas on an 80GB GPU. Single GPU residency and short 128-token pilot first; checkpoint to local artifacts. If OOM, record it and run a revised calibration; do not claim completion.
5. **Benchmarks:** same model/data/processing/evaluation protocol and matched training token budgets. Distinguish cache byte reduction from TTFT, throughput and accuracy. Training-free B0 is not a valid control for attribution of additional B1 training.
6. **Tests:** first `python -m pytest -q tests` on CPU; then actual Qwen/H100 layer/cache smoke; then frozen-base optimizer step; then independent benchmark. A mock unit test never certifies 27B runtime. No source overwrite from another agent without coordinator admission.
7. **GitHub:** direct clone/pull and push only. Do not create `.github/workflows`, use Actions, workflow runs, `workflow_dispatch`, CI endpoints or workflows as logs. One writer integrates reviewed changes with expected source head and readback. Do not commit weights, private data, credentials or unreviewed logs.
8. **Status labels:** planned, implemented, CPU-tested, H100-tested, training-started, ablation-confirmed, blocked. Attach real evidence before advancing a label. A source push never implies a job is running.
9. **Parallel agents:** assign disjoint tasks and artifacts, one integration writer; independent reviewer gets frozen metrics without the author's claimed expected verdict. Preserve original task scope and negative findings.
10. **Long tasks:** actual H100 jobs require an authorized runner/host and a verified PID or scheduler/job ID. A markdown plan, timer or chat continuation without a compute host cannot run 27B.
